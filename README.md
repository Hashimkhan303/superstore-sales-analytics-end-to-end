Superstore Sales Analysis

📊 Project Overview
Complete sales analysis of Superstore dataset using Python for data cleaning and exploratory analysis, plus an interactive Power BI dashboard.

🛠️ Tools Used
- Python: Pandas, Matplotlib, Seaborn (for EDA & visualization)
- Power BI: Interactive dashboard with KPIs and filters
- Google Colab: Python analysis environment

 📁 Project Structure
superstore-sales-analysis-dashboard/
├── Data/ # Raw and cleaned datasets
├── Notebooks/ # Python analysis notebook
├── Dashboard/ # Power BI file and preview image
├── README.md # Project documentation
├── requirements.txt # Python dependencies
└── .gitignore # Files to exclude



📓 Python Analysis (Google Colab)
The Python analysis includes:
- ✅ Data cleaning and preprocessing
- ✅ Exploratory Data Analysis (EDA)
- ✅ Sales trends by month, category, region
- ✅ Profit analysis and visualizations
